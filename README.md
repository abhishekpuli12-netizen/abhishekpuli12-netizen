## 🔥 Featured Projects

### 🤖 Hybrid RAG Academy Assistant

A retrieval-augmented chatbot that answers questions from academy documents, with grounded answers and measured retrieval quality.

* 🔎 **Hybrid retrieval:** FAISS (all-MiniLM-L6-v2) + BM25 with **cross-encoder reranking** over ~600 chunks
* 📈 **Recall@5: 73% → 93%** and **MRR: 0.61 → 0.84** on a 30-question labeled test set
* ⏱️ Median latency **2.8 s** (p95 4.6 s); reranking added only ~180 ms
* 🛡️ Grounded prompts with a "not found" fallback to reduce hallucinations (27/30 faithful answers)
* 💸 **Llama 3 via Ollama**, so zero API cost
* 🌐 FastAPI backend, Streamlit UI, packaged with **Docker Compose**

👉 [View Project](https://github.com/abhishekpuli12-netizen/YOUR-RAG-REPO-NAME)

### 🩺 Fetal Health Classification System

An end-to-end ML system designed for healthcare reliability.

* ⚡ Built using **XGBoost** on 2,126 CTG records
* 📈 **~96% accuracy & ~0.98 ROC-AUC**
* 🎯 Suspect-class **recall improved from 86% to 91%**; all Pathological cases detected
* 🔍 **SHAP** for explainability
* 🌐 Deployed using **FastAPI + Docker**

👉 [View Project](https://github.com/abhishekpuli12-netizen/Fetal-Health-Classification-System-ML-FastAPI-Docker-)
